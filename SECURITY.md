# Security policy

spark-planlock parses plan *text* locally and has no network access or runtime dependencies, so its attack surface is small. If you still find a security issue (for example, a crafted plan that causes unbounded resource use), please **do not open a public issue**. Report it privately through GitHub's [private vulnerability reporting](https://github.com/maazaahmed/spark-planlock/security/advisories/new).

You can expect an acknowledgement within a week. Fixes are released as a patch version and credited in the changelog unless you prefer otherwise.

Only the latest released version receives security fixes.
